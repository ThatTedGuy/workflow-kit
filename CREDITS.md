# Credits

Every third-party asset, library, dataset, and borrowed piece of code in the kit itself gets an entry here **before** it is used. Each project gets its own `CREDITS.md` from the template.

**Allowed licenses:** CC0, public domain, CC-BY, MIT, BSD, Apache-2.0, and zlib. Ask Ted before using anything else, including GPL, LGPL, CC-BY-SA, any NonCommercial or NoDerivatives license, or anything unclear.

## Entry format

```
### Name of the asset, library, or dataset
- Files: `path/to/file`, `path/to/folder/`
- Package: `package-name`
- Source: https://...
- Author: who made it
- License: MIT / CC-BY 4.0 / ...
- Attribution: the exact credit text the license asks for, or "none required"
- Added: YYYY-MM-DD
```

- `Files:` lists every path the entry covers. A path ending in `/` covers everything in that folder.
- `Package:` lists package names from the package manager. Leave it out for plain files.

## Entries

None. The kit is original work under its own `LICENSE`, and uses no third-party libraries, assets, or code. It runs on Claude Code, Git, and PowerShell, which each user installs.
