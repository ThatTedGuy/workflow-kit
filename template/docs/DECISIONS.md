# Decisions

Every project decision, newest at the bottom. Add new entries; never rewrite old ones. To reverse a decision, add a new entry that names the one it replaces.

Format:

```
## YYYY-MM-DD — Short title (Step x.y.z)
- Decision: what was decided
- Reason: why
- Rejected: the other options and why not
- Decided by: {{OWNER}} / Claude (with {{OWNER}}'s OK)
```
