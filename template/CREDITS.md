# Credits

Every third-party asset, library, dataset, and borrowed piece of code gets an entry here **before** it is used. `/review-fix-commit` will not commit anything that no entry covers.

**Allowed licenses:** CC0, public domain, CC-BY, MIT, BSD, Apache-2.0, and zlib. Ask {{OWNER}} before using anything else, including GPL, LGPL, CC-BY-SA, any NonCommercial or NoDerivatives license, or anything unclear.

## Entry format

```
### Name of the asset, library, or dataset
- Files: `path/to/file`, `path/to/folder/`
- Package: `package-name`
- Source: https://...
- Author: who made it
- License: MIT / CC-BY 4.0 / ...
- Attribution: the exact credit text the license asks for, or "none required"
- Added: YYYY-MM-DD
```

- `Files:` lists every path the entry covers. A path ending in `/` covers everything in that folder.
- `Package:` lists package names from the package manager. Leave it out for plain files.
